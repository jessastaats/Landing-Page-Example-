# Landing Page Example

A premium, conversion-focused landing page concept designed and developed by **Jessa Staats** as a web design portfolio example.

## What this project demonstrates

- Conversion-focused page hierarchy
- Sales psychology and objection reduction
- Clear CTA placement
- Responsive desktop and mobile design
- Custom HTML, CSS, and JavaScript
- Scroll-based reveal interactions
- Professional project inquiry form UI
- Strong typography and visual hierarchy
- Accessible reduced-motion support

## Files

- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — scroll animation and demo form behavior

## View with GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The project is intentionally dependency-light and requires no build process.

## Portfolio note

The contact form is a front-end demonstration. For a live client project, it can be connected to Formspree, HubSpot, a CRM, or a custom backend.
